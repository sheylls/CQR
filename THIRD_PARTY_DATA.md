# Third-Party Dataset Provenance

The bundled benchmark files are provided for reproducible research and remain subject to their original source terms.

- [A*Net](https://github.com/DeepGraphLearning/AStarNet) provides the reference inductive configurations for FB15k-237 and WN18RR.
- [AdaProp](https://github.com/LARS-research/AdaProp) provides the NELL-995 inductive v1-v4 splits.

The CQR repository does not re-license these datasets.
